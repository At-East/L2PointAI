# 点云编辑器 · 车辆 / 轨道分离（pcedit 1.0）

给 `rail_wagon_c70e` 这类"整列点云"做编辑：把**车辆**和**轨道**拆成两个可以独立移动/旋转的组，
改完再导出成新的点云，供 L2PointAI 分析、做仿真样本或做配准。

- 纯 Python + numpy + tkinter，不装第三方库、不要 GPU
- 40 万点现场拖动大约 90 ms/帧（拖动时自动降到 14 万点）
- 读 CSV / PLY / TXT，写 CSV / PLY

---

## 1. 启动

- **双击 `点云编辑器.exe`**（推荐，双击后点「打开点云」选文件）
- 或双击 **`启动点云编辑器.bat`**，或把 CSV 拖到它上面
- 或 **`打开C70E点云.bat`**：直接把 `rail_wagon_c70e.csv` 载入好
- 命令行：`python ui.py "D:\任务\sample\rail_wagon_c70e.csv"`

> `ui.py` 是源代码，双击它只会用编辑器打开，不会运行程序。
> 任何一步打不开，双击 `诊断启动.bat` 看报错。

## 2. 五分钟流程（以 C70E 为例）

1. 打开 `rail_wagon_c70e.csv`（40 万点，30 m 长的轨道 + 13.98 m 敞车）
2. 点顶栏 **「自动分离车/轨」** → 左栏变成
   `车体约 25.9 万` + `轨道约 14.1 万`
3. 右上「目标组」选 **车体**，`ΔY` 填 `3.5`，点 **应用平移** → 车整体挪到轨道旁边
   （ΔX/ΔY/ΔZ 默认都是 0；点完「应用平移」这三个框会自动归零，避免连点两次挪两遍）
4. 要模拟脱轨/偏转：`旋转（绕 Z）` 填 `6`，中心选「组中心」，点 **应用旋转**
5. 顶栏 **导出 CSV** → 得到一个改好的 40 万点文件

撤销 `Ctrl+Z`，重做 `Ctrl+Y`，随时可以退回。

## 3. 界面

```
┌ 顶栏：打开 / 导出 / 自动分离 / 撤销重做        轴测 俯视 正视 侧视 适应 ┐
│ 分组树            3D 视图（左键转，右键平移，滚轮缩放）      变换面板 │
│ 选择工具                                                    自动分离参数 │
│ 显示设置                                                    组信息     │
└ 状态栏：点数 / 选中数 / 渲染耗时 ────────────────────────────────────┘
```

**状态栏**：左边一行是**最近一次操作的反馈**（会一直留着，比如「已分离：车体约 25.9 万　轨道约 14.1 万」），
右边是点数 / 渲染耗时。所以点完按钮如果画面没明显变化，先看左下角那行字。

**分组树**：`●` 显示 / `○` 隐藏，点数实时统计。点一行即选中该组为"目标组"。

**选择工具**（改不想要自动分离时手工修）

| 工具 | 操作 | 说明 |
|---|---|---|
| 旋转视角 | 左键拖 | 右键拖平移，滚轮缩放 |
| 框选 | 左键拉矩形 | 勾「只取可见面」= 只选最前面那一层（深度测试）；按住 Shift 加选 |
| 点选 | 单击 | 选中以该点为中心、半径可调（默认 0.12 m）的球内所有点 |
| 测距 | 点两个点 | 状态栏显示三维距离与 ΔX/ΔY/ΔZ |

选好点后：「把选中点归入目标组」或「把选中点拆成新组」。

**平移 / 旋转**（右侧面板）

| 控件 | 作用 |
|---|---|
| ΔX / ΔY / ΔZ 输入框 + 「−/+」 | 只改**框里的数字**，改完点「应用平移」才真正移动；应用完自动归零 |
| 步长（0.1 / 0.5 / 1 / 5） | 下面箭头按钮一次移动多少，方向键也用这个步长 |
| ← −X　→ +X　↑ +Y　↓ −Y　升 +Z　降 −Z | 点一下立刻按步长移动**目标组**（世界坐标方向，不是屏幕方向） |
| 旋转（绕 Z） | 填角度 + 选中心（组中心 / 世界原点 / 选中点）→ 应用旋转 |
| 复位目标组 / 复位全部 | 把组的变换矩阵清空，回到载入时的位置 |

## 4. 自动分离的判据

不是"猜"，是按轨道几何一条条切的。右栏那五项参数一般不用动（打开文件时已经按点云自动填好），
**改完参数直接点「执行自动分离」**；「重新检测参数」是用点云重新算一遍并覆盖手填值，别在改完参数后点它。

| 顺序 | 规则 | 结果 |
|---|---|---|
| 1 | `z < 轨面 − 道床切深` | 轨道（道砟、轨枕） |
| 2 | 落在钢轨带内（`\|\|y\|−钢轨Y\| < 0.055`）且 `z ≤ 轨面+12 mm` | 轨道（轨头、轨腰） |
| 3 | 轨底带（`< 0.09`，`z ≤ 轨面−0.13`） | 轨道（60 kg/m 轨底宽 150 mm） |
| 4 | `z ≤ 轨面` 且 在车体足迹内 | 走行部（轮对、转向架、闸瓦） |
| 5 | 其余 | 车体 |

对 `rail_wagon_c70e` 自动检测出来的是：轨面 Z ≈ 0.002、钢轨 Y ≈ ±0.718（=1435/2）、
车体半长 6.78 m、半宽 1.61 m。这份数据里没有独立可见的轮对（车体底面直接到轨面），
所以「走行部」分组会自动并进车体，不会留一个空组。

**参数含义**

| 参数 | 作用 | 什么时候改 |
|---|---|---|
| 轨面 Z | 钢轨顶面高度 | 换数据自动检测不准时手填 |
| 钢轨 Y | 两条钢轨中心线到轨道中心的距离 | 标准轨 0.7175，窄轨另填 |
| 车体半长 / 半宽 | 车体在 X/Y 上的半尺寸 | 一节车要单独切出来时收小 |
| 道床切深 | 轨面往下多少算"道床/走行部"的分界 | 车轮露得多就调小（如 0.08）；想看轮对单独成组就调大（0.3 时本数据走行部有 1.3 万点） |

## 5. 命令行（批量造样本）

```powershell
# 车体横移 3.6 m、抬高 5 cm，另存（同时出前后对比图）
python -m pcedit.cli "D:\任务\sample\rail_wagon_c70e.csv" out.csv --move 车体:0,3.6,0.05 --shots preview\c70e

# 脱轨：横移 2.4 m + 落下 0.3 m + 偏转 8°
python -m pcedit.cli in.csv derail.csv --move 车体:0,2.4,-0.3 --rot 车体:8

# 只导出车体，轨道丢掉
python -m pcedit.cli in.csv car_only.csv --hide 轨道

# 换一份数据、手工给参数
python -m pcedit.cli scan2.csv out2.csv --z-rail 0.002 --x-half 6.5 --y-half 1.55 --drop 0.08
```

## 6. 文件格式

| 读 | 写 |
|---|---|
| CSV（`x,y,z,intensity`；也认 L2PointAI 的 `x_m,y_m,z_m`） | CSV `x,y,z,intensity` |
| PLY（**ascii**，含 x/y/z/intensity） | PLY ascii |
| TXT/XYZ（空格或逗号分隔的纯数值） | — |

导出的 CSV 和 PLY 都能被 **L2PointAI** 直接打开（已用 `L2PointAI.exe --selftest` 实测通过），
所以流程可以是：**pcedit 改数据 → L2PointAI 出三视图和 AI 报告**。

## 7. 已知限制

- 旋转只做绕 Z（偏航），没做俯仰/侧翻；要侧翻得再扩
- PLY 只读 ascii，二进制 PLY 请先转一次
- 导出是全量点（40 万点约 10 MB CSV），没有做点云抽稀
- 自动分离依赖"车在直轨上、轨面水平"这个前提；弯道、坡道会切得不准，用参数或框选修
- 一次只处理一份点云（多车/多轨道要分批）

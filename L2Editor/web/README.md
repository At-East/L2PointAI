# C70E 敞车 · 点云脱轨模拟编辑器

把 `rail_wagon_c70e.csv`（铁路 + C70E 敞车 + 钢轨，40 万点）变成一个可以**拖动车体、模拟脱轨**的三维编辑器。

![编辑器界面](docs/preview.png)

## 怎么打开

双击 `index.html` 即可（Chrome / Edge 均可，**完全离线**：three.js r128 已放在 `vendor\`，点云已内嵌在 `data.js`，不需要服务器、不需要联网、不需要装任何东西）。

也可以直接带参数打开特定视角/状态：

```
index.html?view=side&preset=derail
```

`view` = `iso | side | front | top`，`preset` = `reset | climb | derail | severe`

## 界面

| 区域 | 作用 |
|---|---|
| 左栏 · 分类图层 | 四个图层单独显示/隐藏，后面数字是点数；「显示原始位置（残影）」画出车体原始包围盒线框 |
| 左栏 · 位移/姿态 | 横向 Δy、垂向 Δz、纵向 Δx 与侧倾/偏航/点头，逐项可调，实时生效 |
| 左栏 · 脱轨预设 | 一键套用四档状态，可播放动画；「复位」回到正常轨行 |
| 左栏 · 编辑工具 | 框选点、拖动轴（三维 gizmo）、导入 CSV、导出 CSV |
| 左栏 · 视角 | 等轴测 / 侧视 / 端视 / 俯视（快捷键 <kbd>1</kbd>~<kbd>4</kbd>） |
| 右上读数 | 脱轨状态判定、横向偏移、轮轨高差、侧倾角、选中点数 |

操作：左键拖动=旋转，右键拖动=平移，滚轮=缩放，<kbd>R</kbd>=复位。

### 脱轨预设

| 预设 | 横向 | 垂向 | 侧倾 | 说明 |
|---|---|---|---|---|
| 复位 | 0 | 0 | 0° | 正常轨行 |
| 轮缘爬轨 | 0.22 m | −0.03 m | 5° | 车轮爬上轨顶的临界状态 |
| 脱轨倾倒 | 0.72 m | −0.30 m | 26° | 车轮落到轨外、车体侧倾 |
| 严重脱轨 | 1.15 m | −0.55 m | 40° | 车体大幅倾倒并偏转 6° |

位移都相对雷达坐标原点（轨道中心、轨面附近），单位米。

### 框选编辑

1. 点「▭ 框选点」进入框选模式（此时左键不再旋转视角）；
2. 在画面上拖一个矩形，右下角会显示选中点数；
3. 顶部出现工具条：「→ 加入车体」把选中的点并进车体（保持它当前的世界位置），「→ 归为环境」把选中的车体点固定到当前位置并移出车体。

区域分类不理想时可以这样修正，例如把误判成车体的栏杆、或车体上被漏掉的部件补进来。

### 导出

「导出 CSV」把**当前状态**的点云写成 `x,y,z,intensity`（车体已应用位移/旋转），可直接喂给 `L2PointAI.exe`、CloudCompare 或再导入本编辑器。

## 分类规则

自动分类按雷达坐标（x 沿轨道、y 横跨轨道、z 向上，单位米）：

| 类别 | 判据 |
|---|---|
| 车体 | `|y| ≤ 1.65` 且 `z ≥ 0.18` 且 `|x| ≤ 7.05` |
| 钢轨 | `0.60 ≤ |y| ≤ 0.86` 且 `-0.5 ≤ z < 0.25` |
| 地面/道砟 | `z < 0.25` 且 `|y| ≤ 2.6`，或 `z < -0.5` |
| 环境/其他 | 其余 |

车体判据来自实测：C70E 车长 13.976 m（这里 x ∈ [−6.99, 6.99]）、宽 ~3.2 m、轨面以上高 ~3.3 m，两条钢轨中心线在 y = ±0.72 附近（标准轨距 1435 mm）。

## 坐标系

- 点云原始坐标：**x 沿轨道**（−15.13 … 15.00），**y 横跨轨道**（−3.20 … 3.20），**z 向上**（−0.75 … 3.28）
- three.js 内部：`X = x`、`Y = z`（上）、`Z = −y`
- 车体绕自身包围盒中心旋转；横向位移对应急 `Z` 方向

## 文件说明

```
index.html        编辑器全部界面与逻辑
data.js           内嵌点云（int16 量化 1 mm，base64）：位置 / 强度 / 初始分类，约 4.2 MB
vendor/           three.js r128 + OrbitControls + TransformControls（离线）
docs/preview.png  界面截图
gen_data2.py      从 CSV 重新生成 data.js 的脚本（含分类规则与预览图）
```

数据量大改后要重新内嵌，改 `gen_data2.py` 里的 `CSV` 路径后运行即可（需要 numpy / Pillow）。

## 已知限制

- 内置数据是**单帧静态扫描**，车体作为一个刚体整体移动，没有轮轨接触力学、没有动力学仿真；「脱轨」是几何姿态演示。
- 车体与钢轨的分类是几何阈值，遮挡严重或换车型时需要重新标定阈值（或直接用框选修正）。
- 40 万点在集显上也能跑满帧；换更大的点云（>200 万点）建议先在 CloudCompare 里降采样。

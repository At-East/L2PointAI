L2 点云脱轨模拟器  v1.0
======================================================================
输入：Unitree L2 扫描的铁路 + C70E 敞车点云（40 万点，30 m 轨道）
功能：三视图 3D 显示、按图层分类、鼠标直接拖车体、脱轨姿态预设、框选编辑、导出

----------------------------------------------------------------------
一、包里有什么
----------------------------------------------------------------------
web\                     网页版（双击 index.html 即可用，无需安装、无需联网）
  index.html             编辑器主程序
  data.js                内嵌点云（40 万点，int16 量化 1 mm）
  vendor\                three.js r128 + OrbitControls + TransformControls
  README.md              详细说明（分类规则、坐标系、二次开发）

desktop\                 桌面版
  L2Editor.exe           双击即打开一个无地址栏的独立窗口（走 Edge / Chrome 内核）
  www\                   桌面版使用的同一份网页

desktop\experimental\    原生 WebView2 宿主（实验版，见文末说明）

src\                     源码
  gen_data2.py           从 CSV 重新生成 data.js
  Launcher.cs            桌面版启动器（C#）
  Program.cs             WebView2 宿主（实验版）
  app.manifest / AssemblyInfo.cs / app.ico

docs\preview.png         界面截图

----------------------------------------------------------------------
二、怎么用
----------------------------------------------------------------------
【最快】双击 web\index.html —— 浏览器直接打开，离线可用。

【像软件一样】双击 desktop\L2Editor.exe —— 打开独立应用窗口，
没有地址栏和标签页；首次运行会在
%LOCALAPPDATA%\L2PointCloudEditor\profile 建一个专用浏览器配置。

【原生窗口】desktop\experimental\L2PointCloudEditor.exe （实验版，见第四节）

----------------------------------------------------------------------
三、操作
----------------------------------------------------------------------
视角      左键拖空白处＝旋转    右键拖动＝平移    滚轮＝缩放
          快捷键 1/2/3/4 = 等轴测 / 侧视 / 端视 / 俯视，R = 复位

移动车体  鼠标直接按住车体拖动 = 在地面内任意平移（可拖出轨面）
          Shift + 拖动 = 升降（垂向）
          Alt   + 拖动 = 旋转（横向=偏航，纵向=侧倾）

精确调整  左栏滑块：横向 Δy / 垂向 Δz / 纵向 Δx、侧倾 / 偏航 / 点头
          点「精确拖动轴」可出现三维 gizmo，逐轴拖动

脱轨预设  轮缘爬轨 / 脱轨倾倒 / 严重脱轨 / 播放动画 / 复位
          右上角实时显示：脱轨状态、横向偏移、轮轨高差、侧倾角

分类图层  车体 255,424 / 钢轨 51,226 / 地面 93,350 / 环境 0，可单独显隐
          「显示原始位置」画出车体原始包围盒线框，便于对比

框选编辑  点「框选点」→ 在画面上拖矩形 → 「→ 加入车体」或「→ 归为环境」
          用于修正自动分类（例如把被漏掉的部件补进车体）

导入/导出 「导入 CSV…」支持 x,y,z[,intensity] 文本点云；
          「导出 CSV」输出当前姿态下的完整点云，可直接回灌 CloudCompare。

----------------------------------------------------------------------
四、关于 WebView2 实验版
----------------------------------------------------------------------
desktop\experimental\L2PointCloudEditor.exe 是用 Windows 自带 WebView2
运行时做的原生宿主（窗口、图标、深色标题栏都是自己的，不依赖浏览器窗口）。
在这里的测试环境中，WebView2 控制器初始化被系统中止（COM 0x80004004 E_ABORT），
所以默认请用 desktop\L2Editor.exe。若你的机器上能正常初始化，实验版体验更好；
打不开属正常现象，删掉即可，不影响其他两种用法。

----------------------------------------------------------------------
五、数据与分类
----------------------------------------------------------------------
坐标（单位米）：x 沿轨道（-15.13…15.00）、y 横跨轨道（-3.20…3.20）、z 向上（-0.75…3.28）
three.js 内部：X=x，Y=z（上），Z=-y

自动分类（几何阈值，可按需修改 src\gen_data2.py 或 index.html 里的 classifyAll）：
  车体       |y| ≤ 1.65 且 z ≥ 0.18 且 |x| ≤ 7.05
  钢轨       0.60 ≤ |y| ≤ 0.86 且 -0.5 ≤ z < 0.25
  地面/道砟  z < 0.25 且 |y| ≤ 2.6，或 z < -0.5
  环境       其余

依据：C70E 车长 13.976 m（x ∈ ±6.99）、宽约 3.2 m、轨面以上高约 3.3 m；
标准轨距 1435 mm，两条钢轨中心线在 y = ±0.72。

----------------------------------------------------------------------
六、环境要求与限制
----------------------------------------------------------------------
· Windows 10 1809+ / Windows 11；网页版需要 Chrome / Edge / Firefox 等现代浏览器
· 桌面版需要 Edge 或 Chrome（找不到时退回系统默认浏览器）
· 全部离线：three.js 与点云都已随包提供，不联网、不写注册表
· 车体按刚体整体平移/旋转，没有轮轨接触力学与动力学求解，属几何姿态演示
· 点云为单帧静态扫描；换车型需重新标定分类阈值后重跑 gen_data2.py

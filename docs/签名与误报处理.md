# 为什么会被杀软报毒，要不要买代码签名证书

## 一、先区分两件事

| 机制 | 表现 | 与签名关系 |
|---|---|---|
| **SmartScreen** | 双击时蓝屏提示“Windows 已保护你的电脑 / 未知发布者” | 强相关：无障碍签名 + 无下载信誉 → 一定拦；OV 需累积信誉，**EV 立即信任** |
| **Defender 反病毒** | 弹出“发现威胁 Trojan:Win32/Wacatac.B!ml”等并删除 | **弱相关**：签名不是免检通行证，启发式/ML 仍可能误判 |
| 企业策略（AppLocker / WDAC / GPO） | “此应用已被阻止” | 强相关：很多策略**只放行已签名程序** |

所以：**签名能解决“未知发布者/被策略拦截”，但不能保证 Defender 的 ML 启发式不再误报。**

## 二、为什么这个程序容易被误报

- 未经签名、构建时间新、全网**零信誉**
- 单个 exe 里同时有：网络访问（Ollama HTTP、UDP 6201）、文件写入（history/exports）、进程内 P/Invoke 风格的 PE 资源
- .NET 单文件 + WinForms + 图标/清单齐全 → 特征与“打包器生成的小马”相似
- 这类误报的典型命名：`Trojan:Win32/Wacatac.B!ml`、`Win32/Wacapew`、`Program:Win32/UnwantedSoftware`，`!ml` 后缀即机器学习判定

## 三、要不要买签名证书？按场景选

| 场景 | 建议 | 成本 |
|---|---|---|
| 只在自己/几台机器用 | **不用买**。加 Defender 排除项即可（见第五节） | 0 |
| 内部小团队分发 | **自签名 + 导入根证书**（脚本已支持），或统一加排除 | 0 |
| 对外分发给客户（几十人以上） | **先提交误报申诉**（免费、24–72h 生效）；若长期分发再考虑 OV | OV 约 200–400 美元/年 |
| 商业产品 / 要过 SmartScreen 无警告 | **EV 证书**（立即获得信誉）或 OV + 持续下载量 | EV 约 300–600 美元/年 |

> 注意：**自签名对外部用户无效**。别人机器上没有你的根证书，依旧显示“未知发布者/不受信任”，且部分杀软对自签名更敏感。

## 四、签名的正确做法（脚本已备好）

```powershell
# 1) 用购买的证书签名（PFX 方式）
.\sign.ps1 -Pfx .\codesign.pfx -Password 你的口令

# 2) 证书已导入本机存储时用指纹
.\sign.ps1 -Thumbprint <证书指纹>

# 3) 内部分发：自签名（会生成 certs\L2PointAI-selfsigned.pfx / .cer）
.\sign.ps1 -SelfSigned
```

脚本行为：

- 自动定位 Windows SDK 的 `signtool.exe`
- SHA256 摘要 + **RFC3161 时间戳**（默认 `http://timestamp.digicert.com`，务必带时间戳，否则证书到期后旧签名失效）
- 签完打印 `Get-AuthenticodeSignature` 状态、签名者、指纹、文件 SHA256

验证签名：

```powershell
Get-AuthenticodeSignature .\dist\L2PointAI.exe | Format-List Status, SignerCertificate
signtool verify /pa /v .\dist\L2PointAI.exe
```

内部分发自签名还要多做一步：把 `certs\L2PointAI-selfsigned.cer` 导入到目标机器的 **受信任的根证书颁发机构**（`certutil -addstore Root .\L2PointAI-selfsigned.cer`，需管理员）。

## 五、Defender 误报的正规处理

1. **提交误报（免费、最有效）**
   - 地址：<https://www.microsoft.com/en-us/wdsi/filesubmission>
   - 选择 “Software developer” → 上传 exe 或填 SHA256 → 说明“自行开发的点云分析工具，误报”
   - 通常 24–72 小时更新特征库；同一文件再次扫描即可
2. **同时提供可核验信息**，能显著加快人工复核：
   - 文件 SHA256、版本号、构建方式（csc/.NET Framework 4.8）、用途说明
   - 源码或构建脚本（本项目即 `build.ps1`，可复现）
3. **多引擎误报**：若 VirusTotal 上多家报毒，可逐家提交（Kaspersky、ESET、Bitdefender 都有误报表单）
4. **临时放行**（仅限自己机器，不推荐对外）：
   ```powershell
   Add-MpPreference -ExclusionPath "E:\文档\unilidar_l2\L2PointAI"
   ```
   或在“Windows 安全中心 → 病毒和威胁防护 → 排除项”里添加文件夹

## 六、降低误报的工程手段（已具备）

- 完整的版本信息、公司/产品名、图标（`assets\version.rc`）
- 应用清单（asInvoker，无提权）
- 不写系统目录、不写注册表、不装服务（只在自己目录写历史/导出）
- 提供 SHA256 校验文件与源码构建脚本，便于复核
- 固定构建机 + 固定工具链，避免每次二进制特征大改

## 七、结论

- **想解决“未知发布者/SmartScreen/企业策略拦截”** → 需要签名（对外用 OV/EV，内部可自签名）
- **想解决“Defender 杀毒误报”** → 首选 **免费误报申诉**，签名只是辅助
- 现阶段最划算的组合：**提交误报 + 保留 SHA256 + 内部分发自签名**；确定要对外长期分发再买 OV/EV
